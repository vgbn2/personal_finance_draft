# Docs-Sync Skill

Use this skill when completing tasks to ensure documentation remains current.

## Sync Protocol
1. After task completion, check `workspace/STATE.md` and update `Recent Activity`.
2. Update `workspace/HANDOFF.md` with persistent notes.
3. Update relevant project docs (e.g., `ARCHITECTURE.md`).
