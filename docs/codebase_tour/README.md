# Codebase Tour

Guided learning modules trace real source paths and provide bounded labs for engineers new to the repository.

## Contract

- Tutorials teach a trace; they do not own production behavior.
- Commands must state side effects and evidence limits.
- Mutable line numbers, paths, and test counts require periodic source review.
- Canonical contracts live in module pages and Code Atlas records.

Start at [00 — Start Here](00_START_HERE.md). Continue through the numbered modules for native core, data, research, execution, terminal interfaces, web/API, and testing.
