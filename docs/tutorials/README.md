# Sovereign Tutorials (Learning Quadrant)

Welcome to Sovereign tutorials. These step-by-step learning paths walk you through the real system from local zero-key development through live execution.

---

## Learning Curriculum

1. [00. Quick Onboarding & Tour](00_quick_onboarding.md) — 15-minute guided tour of the codebase, invariants, and first runs.
2. [01. Native C++20 Core Engine](01_cpp_core_engine.md) — Build, test, and inspect the high-throughput analytics engine.
3. [02. Data Ingestion & Storage Pipeline](02_data_ingestion_pipeline.md) — Streaming providers to append-only binary TS indices (`storage/data/ts/*.bin`).
4. [03. Strategy, Backtest & ML Workbench](03_strategy_backtest_ml.md) — Developing signals, fast-path evaluation, and ML models.
5. [04. Trading Gateway & Order Execution](04_trading_gateway_live_orders.md) — Sub-positions, broker gateways (Alpaca, Polymarket, MT5), and paper trading.
6. [05. Terminal TUI & CLI Dashboard](05_tui_cli_dashboard.md) — Interactive Ink TUI controls, search, and manual order dispatch.
7. [06. Web Dashboard & Private API Bridge](06_web_dashboard_api.md) — React 19 web frontend, SSE/WebSocket streams, and route protection.
8. [07. Testing Methodology & Fixtures](07_testing_methodology.md) — Contract testing, zero-key fixtures, and regression guarantees.
