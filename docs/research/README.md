# Research Documentation

Validated quantitative theory, model assumptions, and research-only methodology live here.

## Owns

- domain theory and mathematical rationale;
- assumptions used by current research implementations;
- research-only qualification and known limitations.

## Does Not Own

- implementation mechanics, which belong in `docs/atlas/algorithms/`;
- module ownership and public contracts, which belong in `docs/modules/`;
- active experiments, evidence, and blockers, which belong in `workspace/research/` or `workspace/reports/`.
