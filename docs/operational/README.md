# Operational Documentation

Task-oriented guides and runbooks for configuring, verifying, operating, recovering, and deploying Sovereign live here.

## Owns

- prerequisites and ordered procedures;
- expected evidence, failure branches, stop conditions, and rollback;
- explicit side-effect labels for network, data-write, service, host, paper, and live actions.

## Does Not Own

- architecture or module contracts;
- algorithm and data-structure explanations;
- dated execution evidence or current blockers, which belong in `workspace/`.
