User-interface and interaction design specifications live here.

## Owns

- durable interaction principles;
- visual and information-architecture contracts;
- source-linked frontend design specifications.

## Does Not Own

- generated frontend output;
- current implementation topology (`docs/modules/` and `docs/atlas/topology/`);
- session prompts, active design review, or task state (`workspace/`).
