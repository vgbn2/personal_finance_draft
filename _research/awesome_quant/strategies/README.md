# Awesome Quant Strategies

This directory contains a collection of quantitative trading strategies imported from [paperswithbacktest-awesome-systematic-trading](https://github.com/paperswithbacktest/awesome-systematic-trading). Each strategy is implemented in Python and is designed for use with the LEAN engine (QuantConnect).
