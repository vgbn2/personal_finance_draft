## Part I: Multiple Choice Concept Check

- **Question 1:**  Which of the following best describes “Phân bố ergodic”?
    > A. A distribution that rapidly converges to a single, optimal state.
    > B. A distribution that adheres to the properties of a Markov chain and can reach any state within a finite time.
    > C. A distribution solely based on maximum likelihood estimation.
    > D. A distribution characterized by only constant probabilities.

    <details>
        <summary>Reveal Answer</summary>
        B. A distribution that adheres to the properties of a Markov chain and can reach any state within a finite time.  “Phân bố ergodic” defines a key characteristic of Markov chains - the ability to reach any state in a finite time.
    </details>

- **Question 2:**  What is the primary purpose of the "Phép biến đổi Fourier"?
    > A. To simplify complex algebraic equations.
    > B. To convert a function from the time domain to the frequency domain (Fourier domain).
    > C. To calculate the derivative of a function.
    > D. To solve differential equations.

    <details>
        <summary>Reveal Answer</summary>
        B. To convert a function from the time domain to the frequency domain (Fourier domain). The Fourier transform decomposes a function into its constituent frequencies.
    </details>

    > A.  Calculating the derivative of a complex function.

## Part II: Formula Application & Short Answer

- **Question 1:**  An electrical circuit's voltage, V(t), is described by the Laplace transform: L{V(t)} = 1/(s^2 + 9).  Determine the function V(t) using the Laplace Transform.  Show your work.

    <details>
        <summary>Reveal Answer</summary>
        1.  **Start with the definition of the Laplace transform:**  L{V(t)} = F(s) = ∫₀^∞ e^(-st)V(t) dt
        2.  **Inverse Laplace Transform:**  To find V(t), we need to perform an inverse Laplace transform on F(s) = 1/(s^2 + 9). This typically involves using partial fraction decomposition:
           1/(s^2 + 9) = (1/6) * (3s + 1)/(s^2 + 9)
        3.  **Integration:**
            ∫₀^∞  (1/6) * (3s + 1)/(s^2 + 9)  de^(-st) dt = (1/6) * ∫₀^∞ (3s + 1)/(s^2 + 9)  e^(-st) dt
        4.  **Solving the integral**:  This integral can be solved using integration by parts or, more simply, recognizing the form as a standard Laplace transform.  The result is V(t) = e^(-3t) * (cos(3t) + (1/3)sin(3t)).
    </details>

- **Question 2:**  Using the Fundamental Theorem of Calculus, if F(x) = x² - x + 1 and f(x) = x, calculate ∫₀¹ f(t) dt.

     <details>
        <summary>Reveal Answer</summary>
        1. **Apply the Fundamental Theorem of Calculus:** ∫₀¹ f(t) dt = F(1) - F(0).
        2. **Calculate F(1):** F(1) = (1)² - (1) + 1 = 1 - 1 + 1 = 1.
        3. **Calculate F(0):** F(0) = (0)² - (0) + 1 = 1.
        4. **Therefore:** ∫₀¹ f(t) dt = 1 - 1 = 0.
    </details>

- **Question 3:** A linear regression model is defined as:  y = 2x + 5.  Explain the meaning of the coefficients '2' and '5' in this context.

     <details>
        <summary>Reveal Answer</summary>
        The coefficients '2' and '5' represent the slope and y-intercept, respectively, of the regression line.  '2' indicates that for every one-unit increase in x, y is expected to increase by 2 units. '5' represents the point where the regression line intersects the y-axis (when x = 0).
    </details>


## Part III: Practical Exercise

- **Scenario:** A manufacturing company produces widgets. The cost of raw materials (intermediate inputs) per widget is $5.  The company sells each widget for $12. Calculate the “Giá trị gia tăng thuần của doanh nghiệp” per widget.

- **Task:**  Calculate the value added per widget.  Provide a clear answer with units.

    <details>
        <summary>Reveal Answer</summary>
        1. **Calculate the Revenue:**  Revenue per widget = $12
        2. **Calculate the Cost of Inputs:** Cost of Inputs per widget = $5
        3. **Calculate Value Added:** Value Added = Revenue - Cost of Inputs = $12 - $5 = $7
        4. **Therefore, the value added per widget is $7.**
    </details>
