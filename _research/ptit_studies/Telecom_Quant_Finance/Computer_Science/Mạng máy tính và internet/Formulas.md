# 🧮 Formulas for Mạng máy tính và internet

- **Memory Capacity**: $$Dung Lượng = 650 Megabytes$$ - CD-ROM storage capacity.

- **Resolution**: $$Resolution = Number of Pixels$$ - Higher pixel density results in higher resolution.

- **Printer Resolution**: $$dpi = Number of Dots / Inch$$ - DPI represents the number of dots printed per inch of the printed material.

- **CSMA/CD**: $$CSMA/CD$$ - Carrier Sense Multiple Access with Collision Detection - a protocol for multi-access Ethernet networks.

- **TCP/IP**: $$TCP/IP$$ - Giao thức điều khiển truyền thông/giao thức internet, phát triển bởi Robert Kahn, Vinton Cerf và các nhà nghiên cứu khác.

- **ADSL2+**: $$ADSL2+ ~ 24 Mbps$$ - ADSL2+ represents a digital subscriber line technology with a theoretical maximum speed of 24 Mbps.

- **Domain Structure**: $$http://mp3.zing.vn$$ - Illustrates subdomain (mp3), domain level 2 (zing), and top-level domain (.vn).

- **IP Address Structure**: $$IP Address = a.b.c.d$$ - An IP address consists of four decimal numbers (a, b, c, and d) separated by periods, representing a device's location on the internet.

- **Bandwidth Calculation**: $$Bandwidth = Data Transfer Rate * Number of Users$$ - The total bandwidth consumed is calculated by multiplying the data transfer rate (e.g., Mbps) by the number of concurrent users accessing the website.

- **Giải quyết tên miền thành địa chỉ IP**: $$DNS Server -> IP Address$$ - DNS server dịch tên miền thành địa chỉ IP để trình duyệt truy cập website.

- **Phân giải tên miền**: $$DNS Server -> DNS Server$$ - DNS server tra vấn các DNS server khác để tìm địa chỉ IP.

- **DNS**: $$\text{DNS} (Domain Name System)$$ - A hierarchical and distributed naming system for electronic documents in the Internet. It translates domain names to IP addresses.

- **Hyperlink**: $$link = source + destination$$ - A hyperlink establishes a connection between two web pages.

- **HTML Structure**: $$HTML = tag + attribute + content$$ - HTML documents are structured using tags, attributes, and content.

- **Password Encryption**: $$Password = Key + Data$$ - A fundamental concept in password protection, where a key is used to encrypt data, providing security.

- **Data Compression**: $$Compressed Size = Original Size * Compression Ratio$$ - A core principle of compression algorithms, representing the reduction in file size achieved through compression.

- **ipconfig /release**: $$ipconfig /release$$ - Lệnh này giải phóng địa chỉ IP động đã được cấp.

- **ipconfig /renew**: $$ipconfig /renew$$ - Lệnh này yêu cầu cấp phát lại địa chỉ IP động từ DHCP server.

- **Ping**: $$ping <target_ip>$$ - A network utility used to test connectivity to a host and measure round-trip time.

- **Traceroute**: $$tracert <target_ip>$$ - A network diagnostic tool that maps the route taken by packets of data between your computer and a destination.
