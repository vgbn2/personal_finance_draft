**1.  Scenario:** A company is upgrading its network infrastructure. They need to determine the bandwidth required to support 50 concurrent users accessing a website with a theoretical maximum speed of 24 Mbps (ADSL2+). Calculate the required bandwidth.

<details>
  <summary>Reveal Solution</summary>
  <ol>
    <li>**Formula:** Bandwidth = Data Transfer Rate * Number of Users</li>
    <li>Data Transfer Rate: 24 Mbps</li>
    <li>Number of Users: 50</li>
    <li>Bandwidth = 24 Mbps * 50 = 1200 Mbps</li>
  </ol>
  Therefore, the required bandwidth is 1200 Mbps.
</details>

**2.  Scenario:**  A printer manufacturer specifies a resolution of 300 dpi for a particular document.  You need to calculate the number of pixels required to achieve this resolution on a printout measuring 8 inches by 10 inches.

<details>
  <summary>Reveal Solution</summary>
  <ol>
    <li>**Formula:** dpi = Number of Dots / Inch</li>
    <li>We know: dpi = 300</li>
    <li>We know: Total Inches = 8 + 10 = 18 inches</li>
    <li>Number of Dots = dpi * Total Inches = 300 * 18 = 5400 dots</li>
    <li>Therefore, the printer requires 5400 pixels to achieve 300 dpi on an 8x10 inch printout.</li>
  </ol>
</details>

**3.  Scenario:**  A network administrator needs to design a system to handle a large number of requests from clients to a central server. They are considering using Client-Server architecture. Describe how the Client-Server architecture would relate to the DNS (Domain Name System) and IP Address structure.

<details>
  <summary>Reveal Solution</summary>
  <p>In a Client-Server architecture, clients (e.g., web browsers) request resources from a central server.  The DNS plays a crucial role by translating human-readable domain names (like http://mp3.zing.vn) into IP addresses that the server can understand.  The IP address structure (a.b.c.d) uniquely identifies the server's location on the internet.  Clients use the IP address to connect to the server, and the DNS ensures that the correct IP address is always used, even if the domain name changes. The server then responds to the client's request, utilizing the information provided by the IP address.</p>
</details>
