# Project Specification

This project follows the specification defined in [docs/spec.md](docs/spec.md).

## Core Mission
Sovereign is a C++-centered trading platform for market analysis, asset data ingestion, CNN-assisted signal generation, portfolio monitoring, and controlled trade execution.

## Initial Objectives
- Establish file structure for market data, research, CNN, execution, and monitoring.
- Document data contracts and module ownership.
- Define configuration slots.

## Phase 2 Objectives (Next)
- Implement asset identity and universe loading.
- Implement OHLCV parsing and validation.
- Implement technical indicators and data quality reports.
