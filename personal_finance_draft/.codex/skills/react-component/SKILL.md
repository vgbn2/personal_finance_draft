# React-Component Skill

Use this skill when creating new components in `web_page/src/components`.

## Generation Template
1. Create TSX file in `web_page/src/components/`.
2. Create corresponding CSS module in `web_page/src/styles/`.
3. Adhere to functional component pattern using `React.FC`.
4. Include prop type definition.
5. Export as default.
