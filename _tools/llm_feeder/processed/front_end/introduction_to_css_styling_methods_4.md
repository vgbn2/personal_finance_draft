## Introduction to CSS Styling Methods
- **Category:** Front-End
- **Core Concept:** This document explains three common methods for styling HTML elements: internal CSS, external CSS, and inline CSS. Internal CSS involves embedding CSS rules within `<style>` tags in the `<head>` of an HTML document, while external CSS uses separate `.css` files linked to the HTML. Inline CSS applies styles directly to individual HTML elements using the `style` attribute, though this approach is generally discouraged due to potential maintenance issues.
- **Technical Breakdown:**
  - CSS styling is used to control the visual presentation of HTML documents.
  - There are three primary methods for applying CSS: internal, external, and inline.
  - Each method has its advantages and disadvantages regarding maintainability, scalability, and potential for conflicts.
- **Snippet:**
```html
<head>
  <style>
    div { 
      color: white; 
      background-color: black; 
    } 

    p { 
      color: red; 
    } 
  </style>
</head>
```
