## CSS Typography and Image Sizing
- **Category:** Front-End
- **Core Concept:** This document details fundamental CSS properties for controlling text appearance and image dimensions. Specifically, it covers `font-family`, `font-size`, `font-weight`, `text-align`, and image height/width adjustments. Understanding these properties is crucial for creating visually appealing and responsive web pages.
- **Technical Breakdown:**
  - CSS properties like `font-family`, `font-size`, `font-weight`, `text-align`, and `font-size` are used to style text elements.
  - The `img` element's `height` and `width` attributes and CSS properties control image dimensions, preventing layout shifts upon image loading.
  - External CSS files are the most common method for managing styles, linking them via the `<link>` tag in the HTML `<head>`.
- **Snippet:**
```css
img {
  height: auto;
  width: 500px;
}
```
