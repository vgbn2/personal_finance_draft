## CSS Selectors
- **Category:** Front-End
- **Core Concept:** CSS selectors are fundamental for targeting specific HTML elements to apply styles. They allow developers to use various methods like ID selectors (using '#') and class selectors (using '.') to precisely control the appearance of web pages. Understanding selector chaining and grouping techniques further enhances styling capabilities, promoting efficient and maintainable code.
- **Technical Breakdown:**
  - ID selectors target elements based on their unique `id` attribute.
  - Class selectors target elements with a specific `class` attribute.
  - Selector chaining allows combining class and ID selectors for more granular targeting.
  - Grouping selectors reduce code repetition by applying the same styles to multiple classes simultaneously.
- **Snippet:**
```html
<div id="title">My Awesome 90's Page</div>
<div class="lesson-note" markdown="1">
```
```css
#title {
  background-color: red;
}
.read {
  color: white;
  background-color: black;
}
```
