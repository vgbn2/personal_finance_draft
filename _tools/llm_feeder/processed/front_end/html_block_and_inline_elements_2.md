## HTML Block and Inline Elements
- **Category:** Front-End
- **Core Concept:** HTML elements are categorized as either block or inline based on their behavior and how they interact with surrounding content. Block elements occupy the full width available and force subsequent elements onto new lines, while inline elements only take up as much width as their content requires and flow within the line of text. Understanding this distinction is crucial for controlling layout and styling in web development.
- **Technical Breakdown:**
  - Block elements (e.g., `<div>`, `<p>`, `<h1>`) establish a new block at the beginning of a line.
  - Inline elements (e.g., `<span>`, `<button>`, `<a>`) flow within the line of text and don't force breaks.
  - Inline-block elements (e.g., `<img>`, `<input>`) combine properties of both block and inline elements, allowing them to sit on the same line while still having defined width and height.
  - The `display` CSS property is used to control whether an element is block, inline, or inline-block.
- **Snippet:**
```html
// Example of a block element
<div style="width: 200px;">This is a block element.</div>

// Example of an inline element
<button style="width: 100px;">Click me</button>
```
