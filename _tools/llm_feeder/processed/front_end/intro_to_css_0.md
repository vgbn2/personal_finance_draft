## Intro To CSS
- **Category:** Front-End
- **Core Concept:** CSS (Cascading Style Sheets) is the standard language for styling web pages, controlling aspects like layout, colors, and fonts. It utilizes rules consisting of selectors and declarations to apply styles to HTML elements. This foundational knowledge is crucial for creating visually appealing and well-structured websites.
- **Technical Breakdown:**
  - CSS rules consist of a selector and a declaration block.
  - Selectors target HTML elements based on their type, class, ID, or universal nature.
  - Declarations within the declaration block define the properties and their corresponding values to be applied to the selected elements.
- **Snippet:**
```css
* {
  color: purple;
}

div { 
  color: white;
}

.alert-text { 
  color: red;
}
```
- **Cross-Reference:** HTML Structure, Selectors (Universal, Type, Class, ID), CSS Syntax
