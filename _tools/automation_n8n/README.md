# n8n Automation Workflows

This directory is reserved for future **n8n** workflows (`.json` files) to automate signal processing or alerting.

## Potential Use Cases
1.  **Webhook Integration**: Receive signals from `main.py` via HTTP Request node.
2.  **Database Sync**: Query TimescaleDB for trade history and generate reports.
3.  **Discord Formatting**: Advanced message formatting before sending to Discord.

## How to use
Export your n8n workflow as JSON and save it here.
