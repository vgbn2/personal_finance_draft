# Code of Conduct

## Our Standard

Sovereign maintainers and contributors collaborate professionally, respectfully, and with technical honesty. We value evidence, reproducible reasoning, and clear boundaries over status, urgency, or unsupported confidence.

## Expected Behavior

- Discuss technical disagreements with relevant contracts, evidence, and trade-offs.
- Review changes constructively and distinguish observations from verified findings.
- Respect privacy, credentials, provider data, host information, and execution boundaries.
- Acknowledge uncertainty, failed checks, and unverified scopes plainly.
- Keep feedback focused on work, behavior, and decisions rather than personal characteristics.

## Unacceptable Behavior

- Harassment, discrimination, threats, or personal attacks.
- Public disclosure of credentials, account data, private host details, or active execution information.
- Falsifying results, concealing test failures, weakening tests to manufacture success, or claiming unperformed verification.
- Pressuring others to bypass operational or safety controls.

## Resolution

Raise concerns with the relevant domain maintainer when possible. Escalate unresolved conduct, security, or protected-boundary concerns to a Core Maintainer as described in [GOVERNANCE.md](GOVERNANCE.md). Security-sensitive matters must follow [SECURITY.md](SECURITY.md), not public discussion.
