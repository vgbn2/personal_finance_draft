# Plan 2.2: Master Clock & Market Sequencing

## Objective
Implement the `WindowSequenceHandler` in `app/core/clock.py` to ensure global synchronization of market windows. This prevents the bot from getting stuck in expired markets and manages the transition to the next chronological window (e.g., 9:15 to 9:30).

# CODE SKETCH: Window Sequence Handler (app/core/clock.py)
class WindowSequenceHandler:
    async def pre_warm_market(self, target_time: float):
        # Wait until 120 seconds before the window begins
        await asyncio.sleep(target_time - time.time() - 120)
        await event_bus.publish("WARMUP", {"status": "warming_up"})
```

# CODE SKETCH: Global State Synchronizer (app/core/state.py)
class SystemState:
    def __init__(self):
        self.active_market = None
        
    async def listen_for_rolls(self):
        while True:
            new_market = await event_bus.subscribe("WINDOW_ROLLED")
            self.active_market = new_market
            log.info(f"System transitioned to {new_market}")
```
