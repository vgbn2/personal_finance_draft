```python
# CODE SKETCH: Orderbook Slippage Calculator
def get_avg_price(orderbook, size_usd):
    filled = 0
    cost = 0
    for price, qty in orderbook['asks']:
        to_fill = min(qty, (size_usd - cost) / price)
        cost += to_fill * price
        filled += to_fill
        if cost >= size_usd: break
    return cost / filled
```
