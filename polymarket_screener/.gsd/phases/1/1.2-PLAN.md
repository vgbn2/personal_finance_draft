# Plan 1.2: External Data Clients

## Objective
Implement clients to fetch external market data, including OHLCV from Binance and Deribit, Options Greeks from Deribit, and Macro data, which are necessary to price Polymarket probabilities.

## Context
- .gsd/SPEC.md
- .gsd/ROADMAP.md

## Tasks

<task type="auto">
  <name>Binance & Deribit Clients</name>
  <files>
    data/exchanges/binance_client.py
    data/exchanges/deribit_client.py
  </files>
  <action>
    - **`binance_client.py`:** Create a class to fetch historical and realtime spot/futures OHLCV data using `ccxt` or raw requests. Include data freshness checks to avoid using stale data.
    - **`deribit_client.py`:** Create a class to fetch options data, including Implied Volatility (IV) and Greeks (Delta, Gamma, Theta, Vega).
  </action>
  <verify>Run the scripts independently to verify they successfully pull and print recent data points.</verify>
  <done>Both classes successfully retrieve correct ticker and metadata. Stale data raises an exception or warning.</done>
</task>

<task type="auto">
  <name>Stock Options Client</name>

  </files>
  <action>

  <verify>Run `stock_options_client.py` with a symbol like 'SPY' or 'AAPL' and verify Greeks/IV data prints correctly.</verify>

</task>
