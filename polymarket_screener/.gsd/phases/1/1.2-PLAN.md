# Plan 1.2: VPN-Safe API & WebSocket Bridge

## Objective
Create the high-performance communication layer. This implements the "Strict Decoupling" strategy where the Python engine binds to 0.0.0.0 (Windows/WSL safe) and pushes data through a non-blocking WebSocket bridge.
