# Plan 0.1: Project Scaffolding & Environment Setup

## Objective
Establish the minimum viable environment for the backend engine to run and pass its own verification tests. This addresses the "Ghost Environment" and "Silent Exit" problems identified in the final audit.

## Context
- .gsd/SPEC.md
- Project Root

## Tasks

<task type="auto">
  <name>Dependency & Environment Bootstrapping</name>
  <files>requirements.txt, .env.example</files>
  <action>
    Create a `requirements.txt` containing: `fastapi`, `uvicorn[standard]`, `pydantic-settings`, `pyyaml`, `motor`, `numpy`, `scipy`, `rich`, `hypothesis`, `pytest-asyncio`, `web3`, and `eth-account`.
    Create a `.env.example` with placeholders for `POLY_API_KEY`, `POLY_PRIVATE_KEY` (for EIP712 signing), `BINANCE_API_KEY`, and `MONGO_URI`.
  </action>
  <verify>pip install -r requirements.txt --dry-run</verify>
  <done>All necessary libraries are identified and listed with version constraints.</done>
</task>

<task type="auto">
  <name>Baseline Configuration Scaffolding</name>
  <files>config/strategy_params.yaml, config/symbols.yaml</files>
  <action>
    Create the `config/` directory.
    Generate a default `strategy_params.yaml` with parameters like `min_edge: 0.04` and `max_exposure: 0.2`.
    Generate a `symbols.yaml` with a list of default markets to observe (e.g., BTC, ETH, FED_RATE).
  </action>
  <verify>ls config/strategy_params.yaml</verify>
  <done>Engine has valid YAML files to read at startup.</done>
</task>

<task type="auto">
  <name>Test Suite Initialization</name>
  <files>tests/conftest.py, tests/test_smoke.py</files>
  <action>
    Create a `tests/` directory. 
    Implement `conftest.py` with an `asyncio` event loop fixture.
    Create a basic `test_smoke.py` that simply attempts to import the `app` package to verify the Python path and dependencies are correct.
  </action>
  <verify>pytest tests/test_smoke.py</verify>
  <done>A functioning test runner is in place for real verification of subsequent phases.</done>
</task>

## Success Criteria
- [ ] `pip install` completes without conflicts.
- [ ] `pytest` can successfully import the core `app` modules.
- [ ] Config files exist and are syntactically valid YAML.
