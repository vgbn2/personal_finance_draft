# Plan 8.2: Position Sizing — Automated Kelly

## Objective
Replace static position sizing with an adaptive Kelly Criterion sizer that adjusts risk based on signal confidence and historical win rate.

## Context
- app/execution/risk_manager.py
- app/core/portfolio.py

## Tasks

<task type="auto">
  <name>Implement Kelly Sizer Module</name>
  <files>
    - app/execution/risk_manager.py
  </files>
  <action>
    - Create `KellySizer` class.
    - Logic: `fraction = (p * b - q) / b` where p is confidence and b is potential payoff.
    - Apply "Quarter-Kelly" multiplier (0.25) to prevent over-leveraging.
  </action>
  <verify>
    - Run test cases with various confidence (0.5 to 0.9) and verify output sizes are proportional.
  </verify>
  <done>
    - Kelly sizer returns values within [0.0, 1.0] range.
  </done>
</task>

<task type="auto">
  <name>Wire Sizer into Execution Router</name>
  <files>
    - app/execution/execution_router.py
  </files>
  <action>
    - Before order placement, call `KellySizer.get_size(signal)`.
    - Enforce a hard cap of 5% of portfolio equity per trade in the `RiskManager`.
  </action>
  <verify>
    - Mock trade execution with high Kelly output; verify it is capped at 5%.
  </verify>
  <done>
    - Trades are adaptive but safely bounded.
  </done>
</task>

## Success Criteria
- [ ] Position sizes vary based on signal confidence.
- [ ] Hard risk caps never breached.
